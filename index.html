Power Features

Built for Professionals

Every feature designed to save you time and deliver production-quality results.

Live Viewport Preview

See your bevel in real-time as a 3D wireframe overlay directly in SketchUp's viewport. Drag to adjust width, press Up/Down to change segments, press Enter to apply. Zero guesswork.

Interactive Drag Controls

Drag directly on selected edges to increase or decrease bevel width in real-time. Type exact dimensions like 5mm or 1/4" in SketchUp's Measurements box for precision control.

Groups & Components

Works seamlessly on loose geometry, groups, component instances, and nested containers. Handles cumulative transformations and scale automatically.

3-Way Corner Solving

Intelligent sphere-fitted corner patches for 3-way junctions. Transfinite patch fallback for complex corner topologies. No more messy intersections.

Auto-Select Sharp Edges

One click selects all sharp edges above a configurable angle threshold. Bevel entire models in seconds instead of manually picking edges.

Geometry Cleanup Tools

Built-in auto-soften/harden edges, harden bevel borders, and clean coplanar/collinear edge tools. Polish your model without leaving the plugin.

Micro-Feature Engine

Automatic scale-up/scale-down for tiny bevels that approach SketchUp's geometry limits. Create sub-millimeter fillets without artifacts.

Shadow Gap Junction Repair

Three-edge shadow-gap junctions share a rectangular inner recess. Trench walls stay straight even when width and depth differ across edges.
